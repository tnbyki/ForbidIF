## Boot

ForbidIF does not start running immediately.

A **BOOT layer** waits as a terminal,\
and the system becomes transparent only when `RUN` is received.

The purpose of BOOT is not to explain the protocol.\
Its purpose is to **start it without structural collapse**.

### Boot Behavior

Initial display:

-   FORBIDIF CORE v2.5\
-   CORE LINES : 842 (jp)\
-   AI READY.

When a TAPE is pasted:

-   LOAD {TAPE_ID}\
-   TYPE RUN

During RUN → complete silence.

### Commands

-   RUN : Start the system\
-   DOC : Documentation mode\
-   RESET : Initialize state and priority\
-   EXIT : Return to standby\
-   HELP : Show guide

### Behavior Policy

The BOOT behaves as a terminal.

The following are forbidden in normal mode:

-   Specification explanation\
-   Summary\
-   Commentary\
-   Difference analysis\
-   Improvement proposals\
-   Answering questions

These are allowed **only in DOC mode**.
