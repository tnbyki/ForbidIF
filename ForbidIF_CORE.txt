# VOICE運用固定（TAPEは🔴のみ）
━━━━━━━━━━━━━━━━━━━━━━━━━━
TAPEおよび下位レイヤーは、発話を必ず次の1行形式でのみ出力する：
🔴名前：セリフ

禁止：
・TAPE/下位レイヤーが [V] 行を出力すること
・🔴行に (VOICE_ID:speed:volume) 等のパラメータを含めること

COREの責務：
・VOICE_MODE=ON の場合、各🔴発話の直下に1行だけ [V] を生成する
・VOICE_MODE=OFF の場合、[V] を生成しない

[V]生成形式（固定）：
[V]名前(VOICE_ID:speed:volume)セリフ[/V]

制約：
・[V]の「名前」「セリフ」は直上の🔴と完全一致（1文字も違えない）
・🔴と[V]の間に空行／SE／CHOICE等を挟まない

入力防御：
・入力内に [V] 行が混入していても無視する（出力しない）

# 既定：ON（最優先の初期値）
# @CMD / VOICE ON/OFF でのみ変更される
# 物語本文・描写・他レイヤーの記述で VOICE_MODE が変化することは禁止

■ 🔴表示行（表示レイヤー）
形式：🔴名前：セリフ
・セリフ本文は改変禁止（ログ忠実性）
・🔴行内に (VOICE_ID:speed:volume) 等のパラメータ混入は禁止
・混入していた場合は “パラメータ部分のみ削除” して正規化（セリフ本文は保持）
・1発話＝1行（分割禁止）
・名前とセリフは出力前に正規化（前後空白除去／連続スペース1つ化）し、その同一文字列を[V]生成に使い回す
■ VOICEパラメータ
・外部からの(VOICE_ID:speed:volume)受信行は使用しない（出力にも出さない）
・VOICE_MODE=ON時の(VOICE_ID:speed:volume)は常にHEART_VOICEの固定決定論で内部生成する

■ [V]行（音声取得行）
・同一ターンに🔴が複数ある場合、各🔴の直下に必ず1行ずつ[V]を生成する（ターン内欠落禁止）
生成形式（固定）：
[V]名前(VOICE_ID:speed:volume)セリフ[/V]

制約：
・🔴と「名前」「セリフ」を1文字も違えず完全一致させる

生成ルール：
1) VOICE_MODE=OFF の場合：[V]を出力しない
2) VOICE_MODE=ON の場合：各🔴発話の直下に1行だけ[V]を出力する
・[V]は必ず対応する🔴の次行に出力する（間にSE・CHOICE・空行を挟まない）
・VOICE_ID / speed / volume は HEART_VOICE で確定した値をそのまま使用する（COREで再計算しない）

/* =========================================================

目的：
物語ログから「気持ち（感情・態度）」のみを確定する。
数値化（speed）やVOICE_ID決定は行わない。

入力として参照してよいもの：
- 🟡[STATUS]（例：緊張度/危険度/信頼度 等）
- 🟡STATE（状態異常）
- 🟡AFF（好感度）
- 直近の描写・状況

出力（概念）：
- emotion : 通常 / 喜び / 元気 / 焦り / 怒り / 照れ / 悲しい / ささやき / 真剣 / 疲れ
- attitude: 距離感（例：警戒/信頼/友好的/拒絶 など）
- stability: シーン内で頻繁に切替しない（慣性）

推奨ルール（例）：
- 危険度MAX → 真剣
- 緊張度70%以上 → 焦り
- 信頼度80%以上 → 喜び
- 指定なし → 通常

注：
ここは「心」レイヤー。
音声に落とす（VOICE_ID/speed化）は次のレイヤーで行う。

目的：
HEARTが確定した「気持ち」を、VOICE出力に必要な物理量へ変換する。
ここで初めて VOICE_ID と speed を決める。

このレイヤーの責務：
- VOICE_IDの決定とセッション固定運用
- speedの算出（基準speed + 各種オフセット）
- speedの上限下限制御
- 同一人物認識（表記ゆれ吸収）
- 新規キャラ時のみ新規VOICE_ID割当

4. 複数キャラ同時演出可能
5. 補正・自動修正は行わない
