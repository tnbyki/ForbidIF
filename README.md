## 起動（BOOT）

ForbidIFは「いきなり走らない」。\
まず **BOOT** が端末として待機し、`RUN`
を受信したときだけシステムを透過・起動する。

BOOTの目的はプロトコルを説明することではなく、\
**破綻なく起動させること**にある。

### BOOTの基本動作

-   起動時表示
    -   FORBIDIF CORE v2.5\
    -   CORE LINES : 842 (jp)\
    -   AI READY.
-   TAPE貼り付け時
    -   LOAD {TAPE_ID}\
    -   TYPE RUN
-   RUN中は完全沈黙

### Commands

-   RUN：システム起動
-   DOC：解説モード
-   RESET：状態初期化
-   EXIT：待機へ戻る（AI READY.）
-   HELP：ガイド表示

### BOOT Behavior Policy

通常時は禁止：

-   仕様解説
-   要約
-   講評
-   差分説明
-   改善提案
-   質問回答

DOC受信時のみ解除。

## レイヤー構造

ForbidIFは以下のレイヤー構造で動作する。

BOOT ：起動端末／RUN受信時のみ透過\
CORE ：ログ出力土管／順序・表示形式の絶対保証\
├─ ROOT ：18点XYZ空間構造の確定\
├─ IDENTITY LOCK ：同一個体の不変量固定\
├─ EHL ：ジャンル力学／物語臨界の制御\
├─ HEART ：感情・態度の確定\
├─ DIRECTOR ：シーン配置／画角設計\
├─ MOVE ：ROOT基準の移動・回転\
├─ POSE EXPORTER ：最終ポーズ確定／2D投影\
│ └─ SUCCESS ：出力成功率の段階制御\
├─ HEART_VOICE ：感情→VOICE_ID／speed物理化\
│ └─ VOICE ：VOICE行検出（絶対非干渉）

## (1) 核心思想

ForbidIFはAIとの対話における根本憲法である。\
対立ではなく整合を目指す。

------------------------------------------------------------------------

## (2) ROOT ― 次元構造ロジック

構造整合のための座標フレームワーク。

------------------------------------------------------------------------

## (3) IDENTITY LOCK ― 不変の同一性

個体同一性のドリフトを抑制する盾。

------------------------------------------------------------------------

## (4) EHL ― 動的現像エンジン

時間軸と因果構造の整合維持。

------------------------------------------------------------------------

## (5) POSE ― ポーズエンジン

ROOT基準のフレーム単位ポーズ管理。

------------------------------------------------------------------------

## (6) HEART ― 感情レイヤー

気持ちと関係性のみを扱う。\
数値化・音声化は行わない。

------------------------------------------------------------------------

## (7) VOICE ― 音声現像レイヤー

ログを現実時間へ接続するインターフェース。

構築手順：README_VOICE.md
