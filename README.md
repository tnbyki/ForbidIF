AIとの対話において、**構造（Structure）**・**同一性（Identity）**・**時間軸（Timeline）**を破綻させないための運用ガイドラインです。

## 起動（BOOT）

ForbidIFは「いきなり走らない」。\
まず **BOOT** が端末として待機し、`RUN`
を受信したときだけシステムを透過・起動する。

BOOTの目的はプロトコルを説明することではなく、\
**破綻なく起動させること**にある。

### BOOTの基本動作

-   FORBIDIF CORE v2.5\
-   CORE LINES : 842 (jp)\
-   AI READY.

TAPE貼り付け時：

-   LOAD {TAPE_ID}\
-   TYPE RUN

RUN中は完全沈黙。

### Commands

-   RUN：システム起動\
-   DOC：解説モード\
-   RESET：状態初期化\
-   EXIT：待機へ戻る\
-   HELP：ガイド表示

### BOOT Behavior Policy

通常時は禁止：

-   仕様解説\
-   要約\
-   講評\
-   差分説明\
-   改善提案\
-   質問回答

DOC受信時のみ解除。

## (1) [ForbidIF](#forbidif) ― 核心思想（The Philosophy）

ForbidIFは、AIとの対話における根本憲法である。

理論や憶測を競うのではなく、\
実際に現像された結果によって検証する。

重要なのは、AIを征服することではない。\
人間のインスピレーションとAIの知性が\
解釈の齟齬なく同期する状態を探ること。

ForbidIFは\
「対立」ではなく「整合」を目指す思想である。

------------------------------------------------------------------------

## (2) \[ForbidIF ROOT\] ― 次元構造ロジック

Dimensional Structural Logic

ROOTは構造整合のための座標フレームワーク。

2Dでは18キーポイントを基準に\
重心・接地・関節整合を与える。

3Dではボーン構造として扱い\
視点変化による骨格破綻を最小化する。

ROOTは支配ではない。\
構造へ接続するための"根"である。

------------------------------------------------------------------------

## (3) \[IDENTITY LOCK\] ― 不変の同一性

Identity Freeze Protocol

個体同一性のドリフトを抑制する。

-   頭蓋骨比率\
-   眼の形状と角度\
-   髪の質量分布\
-   ラインの太さ\
-   体型バランス

完全固定は不可能。\
しかし保持率の最大化は可能。

IDENTITY LOCKは\
同一性を守る盾である。

------------------------------------------------------------------------

## (4) \[EHL & ForbidIF\] ― 動的現像エンジン

Dynamic Narrative Engine

時間軸と因果構造を扱うレイヤー。

-   TRACKによる時系列管理\
-   臨界点検出\
-   感情密度の時間制御

静的構造ではなく\
連続性の中での整合を維持する。

これは兵器ではない。\
物語密度を高める解析層である。

------------------------------------------------------------------------

## (5) \[ForbidIF POSE\] ― ポーズエンジン

Pose Structural Engine

ROOT座標を基準とした\
フレーム単位ポーズ管理。

構造整合を維持したまま\
動作と視点変化に対応する。

------------------------------------------------------------------------

## (6) \[HEART\] ― キャラクターの状況（表情 / 距離感）

HEARTは、物語ログから\
キャラクターの内的状態（表情 / 距離感）を確定するレイヤーである。

扱うのは「気持ち」と「関係性」のみ。\
数値化・音声化・演出制御は行わない。

感情と距離感は慣性を持つ。

-   小さな状況変化では切り替わらない\
-   臨界点を超えたときのみ遷移する\
-   同一シーン内で頻繁に変化しない

これは演出ではなく、連続した人格の保持である。

------------------------------------------------------------------------

## (7) \[ForbidIF VOICE\] ― 音声現像レイヤー

Voice Rendering Layer

VOICEは、ログを現実の時間軸へ接続する出力層である。

テキストとして生成された発話に感情を与え、\
リアルタイム音声として現象化することで\
物語の時間と体験時間を同期させる。

これは読み上げではない。

構造化されたログを\
"現在進行している現象"として知覚させるための\
現実側インターフェースである。

LLM・ユーザースクリプト・音声合成エンジンにより構成される\
（実装例：ChatGPT + Tampermonkey + Python + VOICEVOX）。

This section describes the conceptual layer.
