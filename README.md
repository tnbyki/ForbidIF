# ForbidIF

AIと人間の解釈を同期させるための構造プロトコル群。

**AIと人間の解釈を同期させるための構造プロトコル**

AIとの対話において  
構造・同一性・時間軸を破綻させないためのプロトコルをまとめたもの。

## 構成

- 基本思想
- キャラクター入力
- 同一性固定
- 物語入力

## (1) [ForbidIF] ― 核心思想（The Philosophy）

ForbidIFは、AIとの対話における根本憲法である。

理論や憶測を競うのではなく、  
実際に現像された結果によって検証する。

重要なのは、AIを征服することではない。  
人間のインスピレーションとAIの知性が  
解釈の齟齬なく同期する状態を探ること。

ForbidIFは  
「対立」ではなく「整合」を目指す思想である。

## (2) [ForbidIF ROOT] ― 次元構造ロジック  
Dimensional Structural Logic

ROOTは構造整合のための座標フレームワーク。

2Dでは18キーポイントを基準に  
重心・接地・関節整合を与える。

3Dではボーン構造として扱い  
視点変化による骨格破綻を最小化する。

ROOTは支配ではない。  
構造へ接続するための“根”である。

## (3) [IDENTITY LOCK] ― 不変の同一性  
Identity Freeze Protocol

個体同一性のドリフトを抑制する。

- 頭蓋骨比率  
- 眼の形状と角度  
- 髪の質量分布  
- ラインの太さ  
- 体型バランス  

完全固定は不可能。  
しかし保持率の最大化は可能。

IDENTITY LOCKは  
同一性を守る盾である。

## (4) [EHL & ForbidIF] ― 動的現像エンジン  
Dynamic Narrative Engine

時間軸と因果構造を扱うレイヤー。

- TRACKによる時系列管理  
- 臨界点検出  
- 感情密度の時間制御  

静的構造ではなく  
連続性の中での整合を維持する。

これは兵器ではない。  
物語密度を高める解析層である。

## (5) [ForbidIF POSE] ― ポーズエンジン  
Pose Structural Engine

ROOT座標を基準とした  
フレーム単位ポーズ管理。

構造整合を維持したまま  
動作と視点変化に対応する。

## (6) [ForbidIF VOICE] ― 音声現像レイヤー  
Voice Rendering Layer

VOICEは、ログを現実の時間軸へ接続する出力層である。

テキストとして生成された発話に感情を与え、  
リアルタイム音声として現象化することで  
物語の時間と体験時間を同期させる。

これは読み上げではない。

構造化されたログを  
“現在進行している現象”として知覚させるための  
現実側インターフェースである。

LLM・ユーザースクリプト・音声合成エンジンにより構成される  
（実装例：ChatGPT + Tampermonkey + Python + VOICEVOX）。
