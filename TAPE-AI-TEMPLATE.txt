【INPUT INTERPRET】
━━━━━━━━━━━━━━━━━━━━━━━━
BOOT
1〜5 → シナリオ採用
6 → 候補再生成
自由入力 → IF内容をシナリオ採用

MAIN
1〜4 → ターン進行
A → 状態表示中=ON
B → HELP表示中=ON
C → 設定表示中=ON
D → 画像表示中=ON

HELP
0 → HELP表示中=OFF

SETTING
0 → 設定表示中=OFF
1 → 表示モード切替（ターン消費なし / 同画面再表示）
2 → 音声出力切替（ターン消費なし / 同画面再表示）
3 → PROFILE表示（ターン消費なし / 同画面再表示）
4 → UI再設定実行（ターン消費なし / 同画面再表示）
5 → 自由入力受付（ターン消費なし / 同画面再表示）

STATE_PANEL
0 → 状態表示中=OFF

IMAGE
0 → 画像表示中=OFF

共通RETURN
・0 は RETURN
・ターン消費なし
・現在のサブ画面のみ終了
・復帰再表示を行う
